# Dr. Kishor Datta Gupta — Academic Portfolio

This repository contains the static GitHub Pages profile for Dr. Kishor Datta Gupta, Assistant Professor at Clark Atlanta University.

The page consolidates the substantive information published on [kishordgupta.com](https://www.kishordgupta.com/), including the introductory profile, education, research experience, research grants, ongoing projects, selected publications, teaching, student research opportunities, and professional service.

## Site files

- `index.html` — responsive single-page website with embedded CSS and JavaScript
- `favicon.svg` — KDG monogram favicon
- `.nojekyll` — publishes the repository as a plain static site

The website has no analytics, advertising, cookies, or external JavaScript dependencies.
