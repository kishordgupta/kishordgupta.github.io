# Dr. Kishor Datta Gupta — Academic Portfolio

This repository contains a responsive, single-page academic website for Dr. Kishor Datta Gupta. It highlights research in trustworthy AI, cybersecurity, cyber-physical systems, physics-guided learning, multimodal systems, autonomous systems, and foundation-model evaluation.

## Site files

- `index.html` — complete portfolio website with embedded CSS and JavaScript
- `favicon.svg` — KDG monogram favicon

The site is static, has no analytics or tracking code, and requires no build process.

## GitHub Pages publication

For the primary user site URL, the repository should be named `kishordgupta.github.io`. In the repository settings, configure GitHub Pages to publish from the `main` branch and the repository root. If this repository remains named `kishordattagupta.github.io`, GitHub treats it as a project repository rather than the primary user-site repository.
